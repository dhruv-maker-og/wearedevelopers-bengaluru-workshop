Verify the entitlement before adding a repo

4

  1. Beside Sessions, select +
  2. Choose Add GitHub repository
  3. Search for the lab repository, then select Add

If the repository is not listed, use Clone repository as the fallback, paste the exact lab URL, and continue.

Public by design

No confidential content

Do not paste private code, customer data, secrets, credentials, or internal documents into files, prompts, issues, or chats.
